Who it serves

Built for both sides of the counter.

For cities

Building departments

  • Reviewers see only their own files; an admin sees and searches everything
  • Task lists sorted by urgency, project size and days waiting
  • Standard notes checked on every sheet the moment a set arrives
  • Statutory clocks, like the 60-day ADU deadline, on every file
  • One flat fee for the whole city, not per seat
For applicants

Owners, designers and architects

  • Each application tracked on its own, with its department and reviewer
  • Numbered circles on your sheets that match the comment list
  • Owner, designer, applicant and reviewer contacts on one screen
  • See which round you're on and what's left before pickup
  • Submit straight from Google Drive or Dropbox

Security and data

The city keeps its records. The AI never approves anything.

Drawings stay where they areApplicants share only the files they pick. Redline keeps small clips, about 1–2 MB per project.
City sign-in with security keysStaff use the city's own accounts. Admins sign in with hardware keys or passkeys.
Every action loggedEach view, approval and change goes into an audit log the city can export.
Reviewers decideEvery AI comment cites a code section and waits for a reviewer. Nothing reaches the applicant unapproved.
